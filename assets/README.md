# Assets Folder

## Audio Files

### wedding-song.mp3
Please add your wedding song MP3 file here and rename it to `wedding-song.mp3`.

The audio player on the wedding invitation page will automatically load this file.

**Recommended specifications:**
- Format: MP3
- Bitrate: 128-320 kbps
- Duration: 2-5 minutes (for a preview/excerpt)
- File size: Under 10MB for better web performance

**Supported formats:**
- MP3 (recommended)
- WAV
- OGG

Simply replace this README.md file with your `wedding-song.mp3` file.
